- **Upstream Synchronization** - Rebased the ten active fork patch branches onto upstream `main` at `b84656d64`, which includes transport `v2.3.2` and `v2.4.0`. The release is cut from that anchor, so it also carries the upstream commits merged after the `transports/v2.4.0` tag.
- **Fork Providers** - SiliconFlow, SiliconFlow CN, DeepInfra, Z.AI, Zhipu and CLI Proxy API are registered alongside upstream's new MiniMax and BytePlus providers in the provider factory, config schema, OpenAPI enum, UI constants and provider harness.
- **Responses-to-Chat Compatibility** - `compat.convert_responses_to_chat` keeps its configstore migration after upstream's newest migrations, keeps the database value when `config.json` omits it alongside upstream's config-file tracking, and is now declared in the management OpenAPI `compat` schema, which rejects undeclared properties.
- **Provider Key Placeholders** - Z.AI and Zhipu key placeholders apply to upstream's restructured API key field, which now leaves GitHub Copilot to its own sign-in tab.
- **CI Egress** - The PR test workflow now blocks undeclared egress, so the SiliconFlow, SiliconFlow CN, DeepInfra, Z.AI and Zhipu API hosts are allowed there as they already are in the core test workflow.
- **Multinode Patch Isolation** - The optional PostgreSQL revision/CAS configuration-sync patch is still excluded from this integration and kept separately on `feat/oss-multinode-config-sync`.
