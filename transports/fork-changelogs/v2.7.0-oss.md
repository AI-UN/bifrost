- **Upstream Synchronization** - Rebased the thirteen active fork patch branches onto upstream `main` at `b437a23df`, which carries transport `v2.7.0` (4 commits past the `transports/v2.7.0` tag).
- **Anthropic Tool Stream Order** - When gateway tool search is active, Anthropic streams emit buffered client tool blocks before the `message_delta` stop reason, and stops from internal tool-search turns are suppressed (upstream issue #10370, not yet fixed upstream).
- **Responses-to-Chat Compatibility** - The `compat.convert_responses_to_chat` migration runs after upstream's new MCP client-credentials, AWS SigV4, OAuth flow-origin and notification migrations.
- **Provider Registration** - SiliconFlow, DeepInfra, Z.AI, Zhipu and CPA stay registered in every shared provider list, including the job-accounting video provider allowlist and the config and Helm schema enums.
- **Log Migration Tool** - `cmd/migratelogsobjectstorage` tracks core `v1.17.0` / framework `v1.14.0`, so it still builds standalone.
- **Multinode Patch Isolation** - The optional PostgreSQL revision/CAS configuration-sync patch is still excluded from this integration and kept separately on `feat/oss-multinode-config-sync`.
