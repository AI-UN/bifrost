- **Upstream Synchronization** - Rebased the eleven active fork patch branches onto upstream `main` at `ddd2f3f7d`, which carries transport `v2.6.0` (3 commits past the `transports/v2.6.0` tag).
- **OpenCode Session Affinity** - Upstream merged PR #7052, so the fork drops its copy of that PR. It now keeps only the hardening upstream lacks: a session is scoped by user ID when no virtual key is set, an unscoped session value cannot pose as another virtual key's scoped session, and a forwarded `x-bf-eh-x-opencode-session` header counts as a session source.
- **Stream Drain** - Upstream now ships the guard that skips draining a stream body already read to EOF. The fork keeps the idle-timeout reader's EOF marker and sets the stream-exhausted key through an internal writer, so plugins cannot overwrite it.
- **Provider Registration** - SiliconFlow, DeepInfra, Z.AI, Zhipu and CPA are registered next to upstream's new MachGen, Baseten, Kimchi and Soniox providers in every shared provider list.
- **Provider Icons** - The SiliconFlow and CPA icons load through `server.base_path`, so they no longer 404 when the dashboard is mounted under a URL prefix.
- **Responses-to-Chat Compatibility** - The `compat.convert_responses_to_chat` migration runs after upstream's newest configstore migrations, the UI default lives in upstream's relocated `coreConfigDefaults.ts`, and the toggle is translated in every UI language.
- **Log Migration Tool** - `cmd/migratelogsobjectstorage` builds standalone again: it tracks core `v1.16.0` / framework `v1.13.0` and repeats core's `mcp-go` replace.
- **Multinode Patch Isolation** - The optional PostgreSQL revision/CAS configuration-sync patch is still excluded from this integration and kept separately on `feat/oss-multinode-config-sync`.
